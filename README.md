## How to use it

- **Browse:** download or clone the repository and open [`hub.html`](hub.html) in a browser. It is the front door to all channels: search, filter by area and concept (ANY / ALL), then open a topic in its channel's `library.html`.
- **Read as text:** [`KNOWLEDGE_INDEX.md`](KNOWLEDGE_INDEX.md) routes by area; [`index/concepts.md`](index/concepts.md) lists every concept with each channel's topics on it; [`index/frameworks.md`](index/frameworks.md) lists the frameworks A–Z; [`index/resources.md`](index/resources.md) lists the resources and links shared in the posts.
- **NotebookLM:** each area has a ready folder of study files in [`index/notebooklm/`](index/notebooklm/); each channel has its own pack in `notebooklm/`.
- **AI agents:** each channel's `agent-kb/SKILL.md` gives an agent the channel's persona and constraints and routes it to the knowledge files.
- **The full guide:** [`TG_INSIGHTS_GUIDE.md`](TG_INSIGHTS_GUIDE.md) (also [`guide.html`](guide.html)).

## What each channel folder holds

`topics/` — the knowledge files, one per topic, with `[msg #id]` provenance and verbatim quotes · `library.html` — the channel's offline library · `README.md`, `SUMMARY.md`, `glossary.md`, `people.md` · `resources/` — resources and links shared in the posts · `notebooklm/`, `agent-kb/` — study and agent packs · `99_qa_report.md` — fidelity and depth checks · `_profile.md` — the channel's profile.

This repository holds the synthesized knowledge only. The original Telegram exports, posts, photos and attached files, and the toolkit that builds the library, are not included, so citations name the source post without showing it, and links to attached files do not open.
