How to use this library

Everything one channel (or one book) taught, organised by topic, with the original messages — or the book's passages — one click away.

  1. Topic tree (left) — domains open into topics. A topic page is the full extracted knowledge: core ideas, frameworks and step-by-step methods, detailed insights, tools, quotes, caveats.
  2. Citations — every #123 chip is a source message. Click it to unfold the original text, images and the text transcribed from image cards or PDFs, right where you are reading.
  3. Click the same #123 chip again (or the × on the message) to fold it away — the page returns to where you were.
  4. Show all source messages at the bottom of a topic lists every message behind it, in order.
  5. Concepts (in a topic's summary card) are cross-channel tags such as emotional-regulation or burnout. Click one to open the Knowledge Hub filtered to that concept: every topic of every channel that teaches it, whatever area it is filed under. Also relevant to names other areas the topic substantially covers.
  6. NotebookLM (in a topic's header) lists the NotebookLM study file that holds this topic and the files of every channel on the same area, with a ready-made folder to upload them together.
  7. Books — a book's library works the same way, with passages instead of messages: for a PDF each #40 chip is page 40 of the file, and citations add the printed page ([#40, p. 37]). An unfolded passage shows its printed page and the book section it belongs to. Topics follow what the book teaches, so one topic may gather pages from several chapters. The book's file itself stays local: Open the book under the title in the sidebar, the Files & Media page and an Open page N in the book link in every unfolded passage open it from the book's raw-exports/ folder. Published copies leave the file out; there those places read Request the book / source and lead to a short request form.
  8. Search (top left) filters topics and searches the original messages too (when they are present — published copies of the library leave the original posts out); click a result to jump to the message inside its topic.
  9. Resources lists everything the posts shared that you can use directly — attached files (PDF guides, checklists, audio), articles and studies, free tools, project websites, free videos and podcasts — each with what it is, why it was shared and its source message; ★ marks what the author recommends. External Links lists products, book store pages, courses, services and personal pages the same way. Each topic page also ends with its own Resources and links section.
  10. Home, People, Glossary, Files & Media, Excluded messages are reference pages for this channel. Photos and attached files open from the channel's raw-exports/ folder, where the original Telegram exports are kept; the original posts themselves sit in library-messages.js next to this page. Published copies of the library leave both out, so there a citation only names the post. Excluded lists announcements and logistics that were deliberately left out.
  11. ← Knowledge Hub goes to the cross-channel hub, where the same subject can be read across all your channels.
  12. ＋ Add / append knowledge base opens the Archivist, for example to append a newer export of this channel (if it is not running, the button starts it; in a published copy of the library without the toolkit it reads ＋ Request a channel and opens a form to suggest a new source). ? opens the full guide.

The sun button switches light and dark. This page is rebuilt automatically whenever the knowledge base changes.

Starting the Archivist…

If the browser asks whether to open TG Archivist, allow it (tick “always allow” to skip the question next time). The panel opens in a new tab in a few seconds.

Start the Archivist

Adding or appending a knowledge base is done by the Archivist, a small local app that did not start from this page.

Start it once by hand: double-click Start Archivist.command in the library folder (the one holding hub.html),
or run python3 tg-archivist/app/server.py in a terminal opened there. It opens at http://127.0.0.1:8765.

On a Mac, that first start also installs the small launcher ~/Applications/TG Archivist.app, and from then on this button starts the Archivist by itself.
